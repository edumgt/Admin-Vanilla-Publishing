# Admin Vanilla Publishing

This repository contains the Admin Vanilla Publishing project resources.

## Repository Structure

- `public/`: static frontend pages
- `backend/`: Python backend service
- `backend_fastapi/`: FastAPI backend service
- `infra/`: infrastructure setup resources
- `docs/`, `DOCS/`: project documentation and assets
- `tests/`: test scripts

## Getting Started

1. Review the relevant backend README (`backend/README.md` or `backend_fastapi/README.md`).
2. Run the services using the provided Docker files or shell scripts.
3. Open pages in `public/` for frontend previews.
